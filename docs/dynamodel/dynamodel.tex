\caption{\textsc{Dynamodel} architecture (Phase 1 + Phase 2). State factorization $s_t = (z_{\text{fast}}, z_{\text{slow}}, d_{\text{dyn}}, r)$. Solid black arrows : forward signal. Dashed red : router gating into the mixture dynamics. Orange : connections feeding the loss components. Each transition module $\Phi_k$ has a regime-specific initialization scale (0.3, 0.6, 1.0) acting as a weak inductive bias. Loss weights are regime-conditional : $\mathcal{L}_{\text{slow}}$ and $\mathcal{L}_{\text{recur}}$ are gated by $r_{\text{periodic}}$, $\mathcal{L}_{\text{lyap}}$ by $r_{\text{chaotic}}$, $\mathcal{L}_{\text{sup}}$ provides supervised regime CE. Total parameters : 30K (Phase 1, $d_{\text{slow}}{=}32$) to 134K (Phase 2 on DINOv2 features, $d_{\text{slow}}{=}64$). Phase 2 final result : $28\times$ better one-step OOD prediction than matched-capacity flat-GRU baseline, router accuracy 0.84.}
